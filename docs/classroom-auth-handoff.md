# 학습 화면 임시 진입 경로와 인증 전환

현재 강의 상세의 질문·답변 링크 하나를 로그인 연동 전 학습 화면 확인용으로 남겼습니다.
강의 상세의 학습 도우미 링크는 제거했으며, 학습 화면 내부의 챗봇은 유지합니다.
현재 로그인 제한이 구현된 것은 아닙니다. /qna, /assignments, /chatbot 직접 접근은 미리보기 상태입니다.

로그인 연결 시:
1. detail.jsp의 data-preview-classroom-link 및 TODO(auth) 임시 링크를 제거합니다.
2. 로그인 확인 후 정식 학습 진입 버튼을 제공하고, 비로그인은 로그인으로 안내합니다.
3. 서버에서 학습 페이지와 영상·자료·과제·질문 API 요청의 인증을 검사합니다. 링크 숨김만으로 보호하지 않습니다.
4. 유료 강의의 수강권 확인 조건과 로그인 후 복귀 경로는 백엔드와 확정합니다.
5. 비로그인의 직접 URL 접근과 만료된 인증 요청이 거절되는지 검증합니다.
