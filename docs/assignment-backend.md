# 과제 API 연결 협의

현재는 JSP 본문 + 공통 React 헤더이며 모든 제출 내역/피드백은 화면 미리보기입니다.
미리보기의 PDF/10MB 제한, 과제 제목, 피드백 문구를 실제 정책으로 간주하지 않습니다.

| 항목 | 백엔드와 정할 내용 |
|---|---|
| 과제 조회 | courseId, lessonId, assignmentId와 제목·설명·마감일·허용 확장자·최대 크기 응답 |
| 내 제출 내역 | 로그인 사용자 기준 조회, 제출 일시·메모·첨부 ID·제출 상태·피드백 |
| 제출/재제출 | multipart 업로드 필드명, 재제출 허용 여부, 마감 처리, 중복 요청 처리 |
| 다운로드 | 파일 ID에 대한 본인/담당 강사 권한 검사 후 파일 제공 |
| 피드백 | 강사 작성 권한, 작성자·본문·작성 시각, 대기/완료 상태 |
| 인증 | React와 JSP의 공통 세션 또는 토큰 규칙, 세션 방식이면 CSRF 처리 |
| 오류 | 401/403, 과제 없음, 마감, 파일 초과, 실패 후 재시도 표시 |

서버는 클라이언트가 보낸 사용자 ID를 신뢰하지 않고 로그인 사용자와 수강 권한을 검사합니다.
파일 확장자/크기뿐 아니라 내용도 검사하고 업로드 파일을 실행 가능한 웹 경로에 두지 않습니다.
메모와 피드백은 기본 텍스트 출력합니다. 현재 구현도 사용자 문자열은 textContent로 표시합니다.

실제 API 연결 시 assignments.js의 메모리 상태를 조회/제출 응답으로 교체하고 성공 응답을 받은 뒤에만 제출 완료를 표시합니다.
피드백 예시 토글과 미리보기 문구는 실서비스 연결 시 제거합니다.

## 첨부 선택 정책
과제 내용 또는 PDF 첨부 중 하나가 있으면 제출할 수 있습니다. 둘 다 비어 있으면 거절합니다. 백엔드 연동 시 첨부 필드는 선택 사항으로 받고 같은 규칙을 서버에서도 검증해야 합니다. 첨부한 경우에는 기존 파일 형식·크기 검증을 적용합니다.
