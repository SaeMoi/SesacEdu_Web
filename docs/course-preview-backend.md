# 30초 강의 미리보기 연결 안내

## 현재 구현
- 강의 소개의 `강의 미리보기` → `/courses/preview?id=강의ID`로 이동합니다.
- 선택한 강의의 제목·설명을 표시하고, 30초 이후에는 잠금 안내와 로그인·수강권 확인 버튼을 표시합니다.
- 과제·강의자료·질문답변과 이후 목차도 미리보기 화면에서는 잠겨 있습니다.
- 실제 영상 파일은 아직 없습니다. 화면에 명시된 시연 타이머로 30초 경과/일시정지/다시보기를 확인합니다.
- `jsp/assets/preview.js`의 video 이벤트 처리는 실제 소스 연결을 위한 준비이며, 서버 접근 제어를 대체하지 않습니다.

## 백엔드와 합의할 항목
1. **미리보기 파일:** 원본에서 처음 30초 이하를 잘라 별도 파일로 생성합니다. 비로그인 사용자에게는 이 파일만 제공합니다. 전체 원본을 내려준 뒤 JavaScript로 멈추는 방식은 사용하지 않습니다.
2. **원본 보호:** Java/Tomcat에서 로그인 및 해당 강의의 수강 권한을 확인한 뒤 원본 재생을 허용합니다. Apache 정적 경로로 원본을 직접 열 수 없도록 저장·서빙 경로도 분리합니다. Range 요청이나 HLS 사용 시 재생목록·조각 파일에도 권한이 적용되어야 합니다.
3. **공통 인증:** A의 JSP와 B의 React가 동일한 로그인 상태/수강 권한을 사용할 수 있도록 세션 쿠키 또는 토큰 정책을 합의합니다. 로그인 여부만으로 유료 강의를 허용하지 않습니다.
4. **재생 응답:** 공개 미리보기 URL·실제 길이와 권한 있는 사용자의 전체 재생 URL을 구분합니다. 만료되는 서명 URL을 사용하더라도 URL 만료 시간 30초와 영상의 첫 30초 제한은 서로 다른 개념입니다.
5. **학습 기능:** 과제·자료·질문답변 API에서도 서버 권한 검사를 합니다. 프론트의 잠금 버튼만으로 제한하지 않습니다.
6. **기존 개발용 진입로:** 인증 연결 시 `/qna`, `/assignments` 등 학습 화면과 자료 요청을 보호하고, 강의 소개의 임시 `강의상세` 링크를 제거/정식 수강 진입로로 대체합니다. 현재 미리보기 UI 추가만으로 기존 개발용 화면이 보호되지는 않습니다.

## 제안 API (아직 구현된 명세가 아님)
| 요청 | 역할 |
| --- | --- |
| 미리보기 API: 명세에 없음 | 버튼 제거 상태. 필요 시 별도 협의 |
| GET /lectures/{Lid}/learn | 첨부 명세의 강의 수강 경로. 실제 응답 필드는 별도 확인 |

권장 응답: 인증 없음 401, 수강 권한 없음 403, 없는 강의 404. 구매/로그인 완료 후 원래 강의로 복귀하는 경로도 합의합니다.

## 확인 시나리오
- 비로그인 상태에서 공개 미리보기는 열리고, 원본 URL 직접 요청은 거절됩니다.
- 로그인했지만 미구매인 사용자도 원본은 거절됩니다.
- 구매한 사용자만 전체 강의와 허용된 학습 자료를 볼 수 있습니다.
- 첫 30초 반복 재생은 허용하는 정책입니다. 계정당 1회 제한이 필요하면 별도 서버 기록 정책이 필요합니다.

참고: [OWASP Authorization Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html)의 모든 요청 및 정적 리소스 권한 검사 원칙.
